# 振込機能 追加実装計画

## 優先順位

1. バリデーションの実装
2. エラーメッセージの表示
3. UIの改善
4. 追加機能の実装

## 実装予定

| 優先度 | 内容                                     | 目的                                                                                                                                     | 状態             |
|---|------------------------------------------|------------------------------------------------------------------------------------------------------------------------------------------|------------------|
| 高 | 必須入力チェック                         | 入力漏れを防ぐ                                                                                                                           | 完了             |
| 高 | 振込金額を1円以上に制限                  | 不正な金額を防ぐ                                                                                                                         | 完了             |
| 高 | 過去の振込指定日を禁止                   | 不正な日付を防ぐ                                                                                                                         | 完了             |
| 中 | 確認ダイアログのキャンセル処理           | 誤操作を防ぐ                                                                                                                             | 完了（DB確認済） |
| 中 | 口座番号の7桁指定                        | 日本の振込システムの共通規格（全銀フォーマット）にあわせる<br/>（口座番号は7桁、空きスペースは0梅と指定されてる）<br/>・ユーザの入力ミスを防ぐため | 完了（DB確認済） |
| 中 | 入力欄の説明・入力例を追加               | 入力しやすくする                                                                                                                         | 未対応           |
| 中 | 確認画面の金額を3桁区切りで表示          | 読みやすくする                                                                                                                           | 未対応           |
| 低 | 画面全体のデザイン改善                   | 視認性を高める                                                                                                                           | 未対応           |
| 低 | 確認画面キャンセル時に入力内容を保持する | 操作性を高める                                                                                                                           | 未対応           |

## 実装時の注意

- 既存機能が動かなくならないよう、変更後に入力・確認・完了画面を確認する
- HTMLだけでなくJava側でも入力値を検証する
- 追加機能ごとに動作確認を行う
